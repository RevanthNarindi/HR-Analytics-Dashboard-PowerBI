# HR Analytics Dashboard – Power BI

## Project Overview

This project focuses on analyzing employee attendance using Power BI. The dashboard provides insights into workforce attendance patterns, employee-wise performance, and monthly and yearly attendance trends.

## Business Objectives

- Analyze employee attendance year-wise and month-wise.
- Track present days and absent days.
- Calculate employee attendance percentages.
- Identify top-performing and low-attendance employees.
- Support HR teams in monitoring workforce attendance.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- SQL

## Dashboard Features

- Attendance Overview
- Monthly and Yearly Attendance Trends
- Employee-wise Attendance Analysis
- Present and Absent Days
- Attendance Percentage
- Top 10 and Bottom 10 Employees

## Key Insights

The dashboard helps HR teams understand employee attendance patterns, identify attendance gaps, and make data-driven workforce decisions.
